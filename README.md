# Сайт студии nail.lounge

Минск, пр-т Независимости, 11/2 · метро «Площадь Ленина» · ежедневно 09:00–21:00.

Статический сайт без зависимостей. Собирается одной командой, на выходе —
обычные HTML-файлы, которые кладутся на любой хостинг. Node 18+,
`npm install` не нужен: внешних пакетов нет.

```bash
npm run build    # собрать сайт
npm run edit     # редактор в браузере — правки без кода
npm run check    # проверить: микроразметку, ссылки, заголовки, размеры кнопок
npm run draft    # собрать черновик: плашка и запрет индексации
npm run phone    # открыть сайт на телефоне из домашней сети
npm run photos   # список мест под фотографии с размерами
npm run pdf -- ФАЙЛ.md   # собрать PDF из markdown-файла
```

## Редактор

**Двойной клик по `START-EDITOR-MAC.command`** (macOS) или
**`START-EDITOR-WINDOWS.bat`** (Windows) — терминал не нужен. Откроется браузер
с админкой: формы, кнопки «выше/ниже/дублировать/удалить», кнопка «Сохранить».

После сохранения данные пишутся в `src/data/*.json`, сайт сразу пересобирается,
рядом в журнале появляются найденные проблемы. Редактор слушает только
`127.0.0.1` и в интернет не смотрит.

| Раздел редактора | Файл данных |
|---|---|
| Студия и контакты | `src/data/site.json` |
| Цены | `src/data/prices.json` |
| Услуги | `src/data/services.json` |
| Мастера | `src/data/masters.json` |
| Тексты страниц | `src/data/content.json` |

Одна правка расходится по всему сайту сразу: цена попадает и в таблицу,
и в список услуг в форме записи, и в микроразметку для поиска.

## Запись

Кнопка «Записаться» есть на каждой странице, а на телефоне ещё и в липкой
панели внизу. Нажатие открывает окно с выбором канала — Telegram, Viber,
WhatsApp, Instagram, звонок — и форму, которая собирает заявку готовым
сообщением для мессенджера. Так запись работает на статике, без сервера.

Когда появится бот или система записи, впишите адрес обработчика в редакторе:
«Студия и контакты» → «Приём заявок». Форма начнёт отправлять туда JSON
методом POST, а при сбое сети не потеряет заявку — предложит мессенджер.

## Фотографии

На местах снимков — заглушки в палитре сайта. Посмотреть список имён
и размеров: `npm run photos`. Положите файл с тем же именем и расширением
`.webp`, `.jpg` или `.png` в `assets/img/` — и соберите сайт заново.
Заглушка уступит место фотографии, вёрстка не сдвинется: размеры уже
прописаны в разметке.

## Дизайн

Светлая лавандовая база, один акцент, много воздуха — интерфейс не спорит
с фотографиями работ.

- **Палитра.** Бумага `#fcfafd`, чернила `#241f2a`, акцент — приглушённая
  лаванда `#7a6494`, подложка `#f1ecf6`. Все цвета живут в переменных
  в начале `assets/css/style.css`: поменяли пять строк — поменялся весь сайт,
  включая значки и превью для мессенджеров.
- **Контраст проверен по WCAG.** Текст к фону — не ниже 4,5:1, контуры полей,
  кнопок и фильтров — не ниже 3:1.
- **Мобильная версия основная.** Тач-таргеты не меньше 44×44 пикселей,
  движение уважает `prefers-reduced-motion`.
- Иконки — контурные SVG в одном стиле, без эмодзи.

## SEO и аналитика

Микроразметка `BeautySalon`, `Service` на каждой странице услуги,
`OfferCatalog` с ценами, `FAQPage`, `Person` для мастеров, хлебные крошки.
Open Graph и превью для мессенджеров, `sitemap.xml`, `robots.txt`,
canonical на https. Cookie-баннер с возможностью отказа: счётчики
загружаются только после согласия — так требует законодательство РБ.

Счётчики Метрики и Google Analytics включаются в редакторе, в разделе
«Аналитика». Пока поля пустые, сторонние скрипты не подгружаются.

## Публикация

Сайт публикуется автоматически при каждом пуше в `main`:
`.github/workflows/pages.yml` собирает черновик и выкладывает его
на GitHub Pages. Адрес — https://ssromanpl.github.io/naillounge/

Черновой режим ставит плашку «Черновик сайта» и закрывает страницы
от поисковиков, чтобы макет с предварительными данными не нашли поиском
и не приняли за настоящий сайт студии. Локально то же самое: `npm run draft`.

Данные сверяются с владельцами студии перед запуском; список вопросов
ведётся отдельно, вне этого репозитория.
